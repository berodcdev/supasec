# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in supasec, please report it responsibly.

**Do NOT open a public issue.**

Instead, email **dev@bernardorodc.com** with:

- A description of the vulnerability
- Steps to reproduce
- Potential impact

You'll receive a response within 48 hours. We'll work with you to understand and address the issue before any public disclosure.

## Scope

supasec is a security testing tool designed for authorized use only. Reports about "vulnerabilities" that are intentional features of the tool (e.g., bruteforce capabilities, data extraction) are out of scope.

In scope:
- XSS or injection in the supasec UI itself
- Credential leakage in logs or exports
- Dependencies with known CVEs
- Docker image security issues
